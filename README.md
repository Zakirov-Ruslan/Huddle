### Discord-like pet-project application - "Huddle"

Its a .Net application implementing an copy of discord application using service-based architecture and .Net Aspire. There is a lot of architecture solutions and template code from [eShop](https://github.com/dotnet/eShop) repository

Approximate architecture (something could have be changed):
![huddle-architecture-diagram](img/huddle-architecture-diagram.svg)


Target of this work:
- Realize MVC application with most popular backend patterns like DDD, Clean Architecture, Repository, Unit of Work, CQRS, Outbox and etc.
- Try to use Aspire for distributed application deployment
- Find out how OIDC Auth pipeline works
